# Ferramentas de Economia

`docs/economy/` contém ferramentas operacionais de mestre para apoiar decisões
de preço, disponibilidade, serviços, recompensas e negociação em mesa.

Esse conteúdo não é lore público automático e não deve alimentar o app de
conteúdo público. Fontes brutas permanecem preservadas em `sources/`; fatos
públicos confirmados ficam em `world/public/economy/`.
