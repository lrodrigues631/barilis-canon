# Mar das Tempestades Eternas

## Descrição Geral

O Mar das Tempestades Eternas é um mar de Barilis. Possui tom de fúria divina.

## Relações Conhecidas

O Mar das Tempestades Eternas tem vínculos conhecidos com Ilha de Skaldheim,
Jotungard e Thalos. Skaldheim é politicamente ligada a Jotungard.
